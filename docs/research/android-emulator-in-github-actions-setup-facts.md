# Android emulator in GitHub Actions: documented setup facts

Status: pages read 2026-11-16. Documentation only; nothing was run for this note.

- Hardware acceleration: a GitHub changelog post (URL dated 2023-02-22; the page text shows 23 February 2023) says larger Linux runners can use hardware acceleration for Android testing, "around 2-3 times faster than not using hardware acceleration", and that users "will need to add the runner user to the KVM user group". https://github.blog/changelog/2023-02-22-hardware-accelerated-android-virtualization-on-actions-windows-and-linux-larger-hosted-runners/
- The `android-emulator-runner` README says the old ARM-based emulators "are no longer supported by Google" and that the Intel Atom (x86, x86_64) emulators rely on graphics and VM acceleration for peak speed. It shows a udev rule step to enable KVM permissions on Linux runners. https://github.com/ReactiveCircus/android-emulator-runner
- The Android emulator documentation says VM acceleration needs a system image matching the host architecture, and warns that "ARM- or MIPS-based system images on Intel or AMD CPUs, can't use the VM acceleration". https://developer.android.com/studio/run/emulator-acceleration
- The action's `target` input lists these values in its `action.yml` on `main`: default, google_apis, google_apis_ps16k, google_apis_playstore, google_apis_playstore_16k, aosp_atd, google_atd, android-wear, android-wear-cn, android-tv, google-tv, android-automotive, android-automotive-playstore, android-desktop. `aosp` alone is not documented among the supported values. The list can change between action versions, and the action's validation code was not read. https://raw.githubusercontent.com/ReactiveCircus/android-emulator-runner/main/action.yml
- A GitHub issue titled "Please support KVM on ARM runners" (actions/runner-images #14062, opened 2025-12-03) shows state: closed as of 2026-11-16. The page fetched does not establish whether it was resolved, so nothing is concluded about KVM on ARM runners. https://github.com/actions/runner-images/issues/14062
