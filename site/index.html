Denyut

Denyut is an assistant you can inspect and change: every behavior lives in plain files. This page runs Denyut's own, unmodified Python core (the same core.py, notes and reminders skills as the DeltaChat bot) inside your browser. It is another channel for the same assistant, with no DeltaChat account and no server.

Notes and reminders are stored in this browser only. Reminders ring while this tab is open; a closed or sleeping tab will not fire them. Free-form model replies are not available here because a hosted model needs an API key that must not live in a web page; commands work. Not validated on a physical phone.
